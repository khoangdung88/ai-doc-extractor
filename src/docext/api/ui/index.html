docext — shipping document extraction

Step 1 — Model & API key

Pick a provider, then a model — providers that can list their own models (e.g. Ollama) show a dropdown. An API key is only asked when the provider needs one; it is sent with each request and never stored.

Step 2 — Choose files

Select one or more PDFs — every file is auto-classified per page (invoice · packing list · booking confirmation), so a combined invoice + packing list works as-is. Then click Extract.
